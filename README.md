# make_deb.yml

Вот пример Ansible Playbook для сборки deb-пакета Nginx с модулем ```ngx_brotli```. Он включает в себя установку необходимых зависимостей, клонирование репозиториев, настройку сборочной среды, сборку и создание deb-пакета.  

### Этот playbook выполняет следующие шаги:

1. Устанавливает необходимые зависимости для сборки Nginx.
2. Загружает исходный код Nginx.
3. Клонирует репозиторий ```ngx_brotli``` и инициализирует подмодули.
4. Конфигурирует Nginx с модулем ```ngx_brotli```.
5. Компилирует Nginx.
6. Создаёт deb-пакет с помощью ```checkinstall```.

### Перед выполнением убедитесь, что:

* Установлен Ansible.
* У вас есть права суперпользователя.
* Утилита ```checkinstall``` доступна на вашей системе.

### Для запуска используйте:
```bash
ansible-playbook -i localhost, playbook.yml
```

# repo.yml
## Этот playbook выполняет следующие задачи:

1. Устанавливает необходимые пакеты (```nginx``` и ```dpkg-dev```) для создания и размещения репозитория.
2. Создает каталог для репозитория.
3. Копирует ранее собранный deb-пакет в каталог репозитория.
4. Создает файл ```Packages.gz```, необходимый для работы репозитория.
5. Настраивает Nginx для размещения репозитория.
6. Перезагружает Nginx, чтобы применить настройки.
7. Выводит URL-адрес репозитория.

## Для использования:

* Убедитесь, что на сервере установлен Nginx.
* Замените переменную ```deb_package_path``` на путь к вашему deb-пакету.
* Запустите playbook:
```bash
ansible-playbook -i localhost, playbook.yml
```
